### Учебный проект Decimal
реализация контейнера **decimal** для вычислений больших чисел
``` c
typedef struct{
    int bits[4];
} h_decimal;
```
bits[0] - bits[2]  
- мантисса числа (от младщей части к старшей)

bits[3]
- знак (бит 31)
- порядок (биты 16 - 23)

### Make
- test - запуск тестов с использованием библиотеки check.h (test/*)
- gcov_report - запуск тестов + проверка покрытия кода decimal библиотеки
- sandbox - запуск кода из песочницы (sandbox/main_check.c)

### доступные функции
- h_decimal.h - основные функции учебной библиотеки
- h_decimal_print.h - доп. функции для вывода содержимого контейнера (и его расширенной версии)
